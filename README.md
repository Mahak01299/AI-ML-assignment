# 🤖 AIML Kaggle Lab

This repository contains solutions to various Artificial Intelligence & Machine Learning lab problems using Kaggle datasets.

---

## 📚 Objectives

* Apply machine learning algorithms on real-world datasets
* Understand preprocessing, modeling, and evaluation
* Build complete ML workflows
